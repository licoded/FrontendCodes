# 大文件分片上传系统

这是一个完整的大文件分片上传解决方案，支持分片上传、断点续传和秒传功能。

## ✨ 主要功能

- **分片上传**: 将大文件切分为多个小片段并发上传，提高上传效率
- **断点续传**: 支持上传中断后从断点继续上传，避免重新开始
- **秒传功能**: 文件哈希检测，相同文件无需重复上传
- **实时进度**: 显示总体进度和每个分片的上传状态
- **并发控制**: 可配置的并发上传数量，平衡速度和服务器压力
- **错误重试**: 自动重试失败的分片上传

## 🏗️ 技术架构

### 前端
- **React 19** + **TypeScript** - 现代化的用户界面
- **Vite** - 快速的开发构建工具
- **Web Crypto API** - 浏览器原生哈希计算
- **自定义 Hooks** - 状态管理和上传逻辑封装

### 后端
- **Node.js** + **Express** - RESTful API 服务
- **Multer** - 文件上传处理
- **原生 fs 模块** - 文件系统操作
- **内存存储** - 文件索引和状态管理

## 📋 API 接口

### 1. 检查文件是否存在（秒传检测）
```
POST /api/check-file
Content-Type: application/json

{
  "hash": "文件SHA256哈希",
  "name": "文件名",
  "size": 文件大小
}
```

### 2. 上传文件分片
```
POST /api/upload-chunk
Content-Type: multipart/form-data

- chunk: 文件分片
- chunkIndex: 分片索引
- chunkHash: 分片哈希
- fileHash: 文件哈希
- fileName: 文件名
- totalChunks: 总分片数
```

### 3. 合并文件
```
POST /api/merge-file
Content-Type: application/json

{
  "fileHash": "文件哈希",
  "fileName": "文件名",
  "totalChunks": 总分片数
}
```

### 4. 获取文件列表
```
GET /api/files
```

### 5. 下载文件
```
GET /api/download/:hash
```

### 6. 删除文件
```
DELETE /api/files/:hash
```

## 🔧 配置说明

### 前端配置
- **分片大小**: `src/utils/upload.ts` 中的 `CHUNK_SIZE` (默认 2MB)
- **并发数量**: `src/hooks/useFileUpload.ts` 中的 `concurrency` (默认 3)
- **API 地址**: `src/utils/upload.ts` 中的 `API_BASE`

### 后端配置
- **端口**: `server/server.js` 中的 `PORT` (默认 3001)
- **存储目录**:
  - 临时分片: `server/temp/`
  - 完整文件: `server/uploads/`

## 🎯 使用流程

1. **选择文件**: 拖拽或点击选择要上传的文件
2. **哈希计算**: 系统自动计算文件哈希值
3. **秒传检测**: 检查服务器是否已有相同文件
4. **分片上传**: 如果文件不存在，开始分片上传
5. **实时进度**: 查看总体进度和分片状态
6. **文件合并**: 所有分片上传完成后自动合并
7. **上传完成**: 显示上传结果和文件信息

## 🔍 特色功能

### 智能哈希计算
- 使用 Web Crypto API 进行 SHA-256 哈希计算
- 支持增量计算，适合大文件处理
- 每个分片都有独立的哈希验证

### 可视化进度
- 总体进度条显示整体上传状态
- 分片网格显示每个分片的详细状态
- 实时更新上传速度和剩余时间

### 错误处理
- 自动重试失败的分片
- 哈希验证确保数据完整性
- 友好的错误提示信息

## ⚠️ 注意事项

1. **文件大小限制**: 默认最大 100MB，可在前端代码中修改
2. **浏览器兼容性**: 需要支持 Web Crypto API 的现代浏览器
3. **存储空间**: 确保服务器有足够的磁盘空间
4. **网络稳定性**: 分片上传对网络中断有一定容错能力

## 📈 性能优化建议

1. **调整分片大小**: 根据网络条件和文件大小调整 `CHUNK_SIZE`
2. **控制并发数**: 根据服务器性能调整并发上传数量
3. **启用压缩**: 可添加文件压缩功能减少传输数据
4. **CDN 加速**: 生产环境可使用 CDN 加速文件传输
